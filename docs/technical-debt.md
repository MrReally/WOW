# Технический долг окружения

## Зависание workspace-команд pnpm

**Наблюдение:** 12.11.2026 при финальной проверке команды `pnpm -r lint` и
`pnpm boundaries` запускали процесс `pnpm`, но не запускали дочерние проверки
и не завершались. В выводе присутствовало только предупреждение о
конфигурационном поле `pnpm.onlyBuiltDependencies`.

**Влияние:** это не изменяет поведение приложения и не относится к Telegram
изменениям. Для релиза проверки были выполнены напрямую на уровне пакетов:
TypeScript для contracts/API/web, API-тесты, dependency-cruiser и production
build web/API.

**Дальнейшее действие:** воспроизвести проблему в чистом окружении, проверить
совместимость версии pnpm с текущей конфигурацией workspace и перенести
`pnpm.onlyBuiltDependencies` в поддерживаемый pnpm-config. После исправления
вернуть финальные проверки к стандартным командам workspace.
